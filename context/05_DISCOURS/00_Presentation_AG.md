# 01 — NZUANE N'EST PAS NÉ AUJOURD'HUI

Cette Assemblée Générale ne marque pas le commencement de NZUANE.

Elle marque le passage à une nouvelle étape.

Pendant plusieurs années, nous avons :

- observé ;
- expérimenté ;
- investi ;
- produit ;
- créé des activités ;
- rencontré des acteurs du territoire ;
- appris de nos réussites comme de nos difficultés.

Aujourd'hui, nous transformons cette expérience en une organisation structurée et durable.

> **Nous passons de l'expérimentation à l'institution.**

# 03 — CE QUE LE TERRAIN NOUS A APPRIS

## 1. LES BESOINS SONT LIÉS

Éducation, pauvreté, emploi, alimentation, vulnérabilité sociale et développement économique ne peuvent pas être traités séparément.

## 2. L'ÉCONOMIE DOIT FAIRE PARTIE DE LA RÉPONSE

Créer de la valeur localement permet de créer des emplois, des compétences et des ressources.

## 3. IL FAUT CONNAÎTRE AVANT D'AGIR

Une politique territoriale sérieuse doit reposer sur des données et une connaissance précise du territoire.

## 4. IL FAUT CONSTRUIRE UN SYSTÈME

Les projets ne doivent pas fonctionner isolément.

> **Les projets NZUANE ne sont pas indépendants.  
> Ils composent un même système.**

# 05 — QU'EST-CE QUE NZUANE ?

NZUANE est un **écosystème de développement territorial centré sur Ebolowa**.

Il cherche à mobiliser :

- les habitants ;
- les compétences locales ;
- les jeunes ;
- les femmes ;
- les entrepreneurs ;
- les institutions ;
- les établissements de formation ;
- la diaspora ;
- les entreprises ;
- les partenaires techniques et financiers.

Autour d'une ambition commune :

> **Permettre au territoire de produire progressivement ses propres capacités de développement.**

# 08 — ROMBONE : PRODUIRE POUR CONSTRUIRE

ROMBONE est une exploitation agricole structurée créée dans l'écosystème NZUANE.

Sa vocation dépasse la seule production agricole.

ROMBONE doit devenir progressivement :

- une exploitation économique viable ;
- un terrain de formation ;
- un support à l'entrepreneuriat ;
- un espace d'expérimentation ;
- un partenaire des acteurs agricoles ;
- une source d'approvisionnement pour certaines actions sociales.

> **Produire de la valeur pour alimenter l'écosystème.**

- la mission ;
- les valeurs ;
- l'ancrage territorial ;
- la cohérence de l'écosystème ;
- la transparence ;
- la continuité de long terme.

> **Construire NZUANE, c'est construire quelque chose qui doit pouvoir nous survivre.**
